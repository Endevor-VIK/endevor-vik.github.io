# AXIOM SHOWCASE V0.3.1 — IMAGE AUDIT (W0)

## 1. Метод

- **Коэффициент резкости** = ширина файла `currentSrc` ÷ (CSS-размер блока × DPR) с учётом `object-fit` (`cover` — по большей стороне, `contain` — по меньшей). `≥ 1` — устройство получает не меньше пикселей, чем показывает; `< 0,95` — растяжение, помечено ⚠.
- `naturalWidth` у `srcset`-картинок браузер отдаёт с поправкой на плотность, поэтому реальный размер брался из файла (Pillow), а не из DOM — первый вариант зонда давал ложные числа и был отброшен (`AUDIT_REPORT.md` §14).
- Визуальная проверка: обрезки 1:1 против оригиналов (PNG Visual Library, lossless WebP скриншотов, PNG портретов), PSNR.
- Источники чисел: `sandbox/evidence/2026-10-16_0524_showcase-v031-w0-audit/baseline/image-sharpness.json` (база) и `w01/image-sharpness-below-0.95.json` (после W0.1).
