## 1. Сводка

1. **P0 на телефонах (исправлено в W0.1):** в разделе WORK блок AXIOM WEB CORE ломался на 360/390/430 px в обоих движках — двухколоночная сетка, арт шириной 924 px, заголовок перекрыт картинкой (`elementFromPoint` попадает в `figure`), текст сжат до ~150 px. Причина — безусловные правила V2.2/V2.3 перебивали мобильные media-запросы V2.1 (класс дефекта «каскад слоёв»).
2. **Резкость:** после выбора экрана в WORK-stage `srcset` обнулялся, и на 1440@2 показывался 960w с растяжением ×2,1 («каша» мелкого UI; снимок `captures/w0/w0-08-stage-sharpness.jpg`). Исправлено: используется лучший доступный исходник 1919w (остаточный апскейл ×1,07 — предел исходника).
3. **Производительность (lab):** Lighthouse mobile по живому сайту — Performance 50, FCP 6,25 с, LCP 8,26 с, CLS 0,125; desktop — 59, LCP 4,13 с. Цели LCP ≤ 2,5 с и CLS ≤ 0,1 **не достигнуты**. Начальная загрузка 2,4 МБ, из них 1,68 МБ — карта для закрытого диалога (исправлено: 733 КБ desktop / 721 КБ mobile).
4. **Палитра:** запрет на розовый/фиолетовый в V2.3 сработал не полностью — V2.3 перекрыл только `background-color`, а «сливовые» градиенты ранних слоёв продолжают рисоваться: доля пурпурно-окрашенных тёмных пикселей — WORLD-гид 43 %, CREATOR 36 %, VISION 31,5 % (для сравнения: футер 1 %).
5. **Типографика и контраст:** 5 семейств / 16 начертаний на каждый визит, две конкурирующие системы заголовков (Oswald в HERO и лоре, Unbounded в новых секциях) и 59 % текстовых элементов мельче 12 px; основной вторичный серый `#6d6e76` даёт 3,88:1, а белый текст на красных кнопках — 3,81:1 (оба ниже AA 4,5:1).
6. **Информационная архитектура:** страница — 38 экранов телефона и 25 экранов десктопа; VISION начинается на ~33-м экране из 38, потому что лор-архив (~17 экранов) стоит между SYSTEM и VISION; WORK показывает одни и те же 8 скриншотов дважды.
7. **Канон:** шесть узлов мира подтверждаются Canon V3, но ряд формулировок лендинга расходится с каноном (OMEGA-0 — подземная лаборатория под Глухой станцией; NIGHTMARE — технология, а не позывной Виктора; «X-CLASS» не найден в каноне). Подробно — `CANON_REVIEW.md`.
8. **Внешнее состояние (OBSERVED 2026-10-16 14:01 UTC):** `ENTER AXIOM` ведёт на `axiomgates.com`, который сейчас отвечает 503 «AXIOM GATE UNAVAILABLE» (брендированная заглушка шлюза, `retry-after: 30`). Это состояние живого контура, а не дефект лендинга; решение о подсказке у CTA — за CREATOR.

## 2. Методика и среда

- **Движки:** Chromium 149.0.7827.55 (Chrome for Testing, headless, SwiftShader — без GPU) и Firefox 151.0 через Playwright 1.61.1 (из `apps/axiom-web-core-ui/node_modules`, ничего не устанавливалось). WebKit не установлен — **NOT RUN**. Реальный GPU (Edge через CDP с Windows) в W0 не использовался — **NOT RUN**.
- **Вьюпорты:** 360×800@2, 390×844@3, 430×932@3, 768×1024@2, 1024×768@1, 1280×800@1, 1440×900@1/@2, 1920×1080@1, «200 % zoom» = 960×540@2; дополнительно 1100/1366/1536/1680 для замера коллизий HERO. Телефоны — `isMobile`+`hasTouch` (Chromium).
- **Съёмка:** первый экран (реальная шапка), страница сегментами по 6000 px, секции и компоненты (шапка/fixed-элементы нейтрализованы — это отмечено в именах файлов `sec-*`/`cmp-*`).
- **Измерения:** геометрия DOM, переполнения, инвентарь размеров текста, резкость изображений (размер файла `currentSrc` ÷ (CSS-размер × DPR) с учётом `object-fit`), сетевой след CDP, PerformanceObserver (LCP/CLS/longtask/event), Lighthouse 12.8.2 (3 прогона, медиана), axe-core 4.12.1, пиксельная выборка оттенка фонов.
- **Серверы:** baseline-worktree `2dbb616` и рабочая ветка — отдельными локальными серверами; для замеров веса — сервер с gzip и `Cache-Control: max-age=600` (как GitHub Pages).
- **Ограничение замеров времени:** CSS Google Fonts идёт через прокси хоста и колеблется 0,5–2,3 с между прогонами; поэтому сравнения FCP/LCP «до/после» в W0.1 **не заявляются**, сравниваются только байты и детерминированные проверки.

Воспроизведение: `REVIEW_HANDOFF.md` §4 и `QA_MATRIX.md`.
