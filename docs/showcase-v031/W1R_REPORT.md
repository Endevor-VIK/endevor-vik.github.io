## 2. R2 — Q-04 по отрисовке

### 2.1 Причина остатка 3,42 %

Красные свечения эмблемы (`#ff2034`, синий канал больше зелёного) лежали на полупрозрачном фоне колонки поверх синеватого разделителя (итог `#19191f`). Грани лепестков были белыми с прозрачностью 82 % поверх красного, а полупрозрачная красная сердцевина — поверх белого центра. Каждое такое смешение даёт сливовый или розовый тон. Проверено послойно: отключение ореола, граней и сердцевины по отдельности.

### 2.2 Что изменено (локально, без уплощения)

| Где | Было | Стало |
| --- | --- | --- |
| Фон колонки эмблемы | `rgba(13,14,18,.6)` поверх синеватого разделителя (= `#19191f`) | непрозрачный нейтральный `#19191b` (та же яркость) |
| Внутренние грани лепестков | белый `fill-opacity .82` поверх красного | непрозрачный градиент `#ffffff → #c3c7cf` (`axPetalLight`): белый свет без смешения |
| Сердцевина (`axCoreG`) | полупрозрачный градиент со стартом `#ffffff` поверх белого центра | старт `#ff4a54`: раскалённый красный центр; белое «сердце» осталось отдельным слоем |
| Ореол (`axHalo`) | `#ff2034` .28/.05/0 | без изменений: на нейтральном фоне даёт тёмно-красный |
| Глитч-обводка `AXIOM∅` | под reduced motion обводка висела видимой (дефект с V2.x); полупрозрачная поверх букв | `opacity:0` в покое, слой под текстом (`z-index:-1`) — анимация та же |
| Свечение `∅` | ложилось на букву M | слой под текстом |
| Цифры фаз (`.show-phase-number`) | `#a81a22` 14 % поверх холодной карточки (читался сливовым) | непрозрачный `#281215` (тёмно-красный) |

Световая динамика сохранена: пульс ореола, вращение колец, глитч заголовка, сканы — кадры t = 0 / 1,05 / 2,1 / 3,15 с.

**Поправка к W1.** Chromium рисует пустые кадры ниже ≈ 20 000 px при снимке «всей страницы». В W1 метрика 390 (страница 30 862 px) поэтому охватывала только верхнюю часть страницы. В W1.R вся страница снимается по сегментам высотой с вьюпорт (`tools/pink-segments.cjs`), числа выше — по всей высоте. Строгое значение W1 0,70 % и строгое значение W1.R по сегментам 0,851 % → 0,653 % сняты разными методами, сравнивать их напрямую нельзя.
