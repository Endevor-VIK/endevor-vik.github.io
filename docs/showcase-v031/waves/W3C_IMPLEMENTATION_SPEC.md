## 1. Контракт задачи

**Цель.** Посетитель входит в WORLD как в художественный мир, а не в досье:
- порог W01;
- утверждение;
- пять глав;
- спуск в OMEGA-0;
- люди и силы;
- эпилог W07 → VISION.

**Не цели.**
- Новые локации, механики инцидента, хронология, причины BLACK SUN.
- Замена карты V10.
- Окна B.
- Прогрев изображений при открытии страницы.
- Перехват прокрутки, snap, обязательная анимация.
- Вывеска «CONCEPT ART».

**Владение файлами.**

| Файл | Что меняется |
| --- | --- |
| `index.html` | `#world-guide`; мета-текст из конца `#system` переносится внутрь; строки и плашки глав в пяти секциях; сцена OMEGA-0 в конце `#world`; эпилог перед полосой VISION |
| `assets/css/showcase-v23.css` | Блок `0524 W3.C` в конце файла |
| `assets/js/showcase-v23.js` | Ссылка «узнать о месте» выбирает узел 02.05; мягкое раскрытие W03 только как прогрессивное улучшение |

| `docs/showcase-v031/**` | Спецификация, отчёт, доказательства, handoff |

**Сохранить без изменений.**
- Порядок 17 секций и якоря `#world-guide #manifesto #modules #world #chars #factions #vision`.
- Узлы карты V10, их выбор мышью и клавиатурой (R42), просмотрщик карты (R39/R40).
- Canon ID `02.01…02.06` по порядку.
- Тексты исходных секций: строки глав только **добавляются**.
- Шрифты TYPE A, RED PROTOCOL `#ff2034`, WORK B, курсор, лоадер, 404.
- Полосы F-06, нумерация R29 `1…7`.
- Работа без JS и при reduced motion.

**Готово (DoD).**
- Слайсы S1–S4 — отдельными коммитами.
- QA на точном SHA:
  - регрессия, включая новые R-W3C;
  - smoke ×2, axe, Lighthouse против BEFORE;
  - без JS, reduced motion, ширины 360…1920;

- Отчёт и handoff.
- Draft PR для ревью, без merge.

**Откат.** Любой слайс откатывается `git revert` своего коммита. Библиотека и документы от кода не зависят.

## 3. Режиссура OMEGA-0 (Act III — спуск)

Место: внутри `#world`, после строки осей карты (`AXIS / GLUHAYA → OMEGA-0 → NEXUS`). Читатель только что увидел шесть узлов и ось — и одна точка оси раскрывается вглубь.

| Такт | Desktop (≥ 1024) | Phone (≤ 760) |
| --- | --- | --- |
| **Подход** | Слева тонкая вертикаль «спуска»: сверху `GLUHAYA STATION`, вниз красная линия, внизу `02.05 / OMEGA-0`. Координат и глубин нет. | Горизонтальная строка `GLUHAYA STATION → OMEGA-0` над кадром. |

С JS и без reduced motion кадр при входе в поле зрения один раз раскрывается сверху вниз. Без JS кадр виден сразу. | Кадр 6:5 по центральной шахте: нижняя часть шахты не обрезана (кадр по высоте целиком). Текст ниже на чёрном. |
