# Сохранение исходного дизайна — R1.P

Это предложение для художественного решения CREATOR. Матрица описывает намерение и проверенные свойства; она не объявляет, что A+ художественно принят.

Источники: BEFORE `6b082e5`, W4 CURRENT `b85fbb0`, начало этого прохода `4836a5d`, Canon `3884ea43`. [Полная директива](PRINCIPAL_CHANGES_REQUESTED.md). A/B/C отклонены. Меняется только изолированный snapshot; продукт остаётся на `b85fbb0`.

[Нативный просмотр всех 346 кадров](../../evidence/w4rp/REVIEW.html) сохраняет исходные размеры: 1440×900, 1920×1080, 390×844, 360×800, DPR 1. Он показывает полные секции, а не уменьшенные иллюстрации введений. [Raw manifest и геометрия](../../evidence/w4rp/manifest.json), [проверка источников](../../evidence/w4rp/source-validation.json).

## Что именно изменено намеренно

1. **Только A+ snapshot:** из WORK 02/03/05 убраны три упрощённых disclosure. Их заменяет одна полная четырёхмодульная экспозиция **внутри того же WORK**, после real archive и dialog, перед существующим `#work-intro`; далее идёт исходный SYSTEM. В CURRENT все disclosure сохранены. Восемь реальных figures/cases и viewer совпадают с исходными.
2. **Four Surfaces:** убрана исходная верхняя полоса фиктивных `INDEXED / WORLD NODES / CANON DEPTH / SYNC DRIFT / PROTOCOL` показателей. Модули с рамками/объектами не сокращены. Условные версии, PUBLISHED/LIVE/SYNC/TRACE/20 ENTRIES и чужой псевдо-ID досье заменены ясными model labels/качественными ролями. Переносы `<br>` в нескольких старых метках заменены естественным block layout; это единственная разница в графической tag topology. SVG geometry/attributes exact.
3. **Доктрина:** вместо краткой W4-цитаты восстановлены три крупные рамы и пять оформленных фрагментов. Левый столбец — происхождение/NEXARCH, правый — исторические вопросы. ENTROPY/DRIFT/DECRYPTING и ложная подписанная команда не возвращены. Восстановлена архитектура, не недостоверные утверждения.
4. **Пять фрагментов:** исходные названия Controlled Amputation / Fragmented Core / Echo Layer / Black Protocol / Bio Variable заменены качественными RELIC/ECHO/CONTROL/BIO/MYTH по 03.03 B05. Сохраняются исходные рамки и пять глифов. Это литературная панорама остаточного присутствия, не пять программ/закрытая карта и не биологический механизм. В AXIOM ∅ остаётся исходное подробное раскрытие. Это отличается от прежнего намерения R0 не вводить дополнительный ряд: новый ряд нужен для восстановления исходной композиции по Principal preservation directive; его новая смысловая редакция явно предлагается CREATOR.
5. **Aftermath:** W02 вынесена из узкой плашки в крупную сцену памяти; W04 повторно использована в вертикальном образе допуска; добавлен code-native объект человека и технической зависимости. Нет нового bitmap/места/персонажа или медицинских измерений. Неизменные три темы изложены через человеческие последствия.
6. **WORLD:** только старый внешний вопрос/второй h2 заменены одним ENG/RU overlay на исходной W04; обновлены внешние два вводных абзаца. Все внутренние географические объекты/оси/OMEGA untouched.
7. **CHARACTERS:** удалена только внешняя chapter-line; заменены внешний h2 и вводная. Protected карточки/портреты/биографии/отношения/AXIOM ∅ exact.
8. **Responsive:** у полной орбиты малые карточки перенесены вниз без перекрытия; CONTENT signal не скрывается, а располагается ниже досье; radar/log располагаются последовательно. Новое повествовательное чтение использует 16–17 px; метки и рисунки сохраняют техническую иерархию. Normal motion остаётся декоративным; RM показывает конечные состояния.

W01, реальный архив, SYSTEM, FACTIONS/неопределённость NEURA, эпилог, VISION и CONTACT остаются текущими W4. Два исходных HERO-дефекта не исправлялись. Canon и protected сцены не менялись.
