## 2. Решения по пунктам Principal

Все решения собраны в одном прототипе **A+AD**. Это снапшот A+ и один стилевой слой; карта, портреты и прочие protected-блоки побайтно равны A+ (§6).

### P1 / DOCTRINE — терминал получает содержание, фрагменты получают свою функцию

**AD-01. Пропорции трёх зон.** Боковые колонки — 236 / 248 px вместо 210 / 230, `min-height` терминала снят, заголовок правой зоны — 30 px, печать вопросов — 104 px. Архив не уменьшен: центр остаётся кульминацией.

**AD-02. Нижний регистр терминала.** В нём теперь два объекта, а не пустота:
- **«Разорванное кольцо».** Пять дуг вокруг пустого центра `∅` разнесены на разную дистанцию. CONTROL — ближе всех, залит и зажат двумя скобами. Это буквальная визуализация текста слева: «Целостность утрачена. Фрагменты остались. Слой контроля удержан. Но это не весь AXIOM». Пустой центр рифмуется с AXIOM ∅ в CHARACTERS. Объект декоративный (`aria-hidden`): смысл несёт текст.
- **Реестр состояния:** `01 ФРАГМЕНТИРОВАН · 02 НЕ СТЁРТ · 03 НЕ ВОССТАНОВЛЕН`. Это Canon 03.03 B05.S03: *AXIOM is fragmented. AXIOM is not erased. AXIOM is not fully restored.* Нижняя полоса показателей была частью исходного дизайна, но держала фальшивые `SIGNAL 0.84 / DRIFT 0.02%`. Возвращаю ту же архитектуру с правдивым качественным содержанием. Figcaption уточнён: реестр соответствует канонической модели фрагментации, остальная запись — авторская.

**AD-03. Пять фрагментов → «Пять следов. Одно имя.»** Это главное смысловое решение. Опора — Canon 03.03 **B05.S05 Recognition Errors**: разные люди встречают разные режимы и называют всё одним словом AXIOM.

| Режим | Доктрина A+AD: **кто встречает и что принимает за AXIOM** | AXIOM ∅: **чем режим является** (не тронут) |
| --- | --- | --- |
| RELIC | «Ядро под печатью»: технократы видят доказательство, что сборку можно провести инженерной процедурой | SEALED: запечатанные фрагменты кода, голоса, реликтовые ядра |
| ECHO | «Голос, который отвечает»: подполье слышит возвращение целой личности; «но эхо — только отражение» | DRIFT: петли, фантомные ответы |
| CONTROL | «Рычаги порядка»: власть принимает удержанный слой за остаток полного господства | CAGED: удерживаемый NEXARCH слой |
| BIO | «Слепое пятно»: **не ошибка узнавания, а скрытое присутствие** (B05.S02) — контуры не до конца доступны цифровой клетке; пунктирная рамка, подвал `РЕЖИМ / СКРЫТОЕ ПРИСУТСТВИЕ` | HIDDEN: скрытые контуры в носителе |
| MYTH | «Знамение»: культы принимают отклик за божественное явление | RUMOR: культовый образ в подполье |

Подвалы карточек (`ВСТРЕЧАЕТ / ПРИНИМАЕТ ЗА`) заменяют одинаковое `AXIOM · ПРИСУТСТВИЕ ФРАГМЕНТ`. Вводная к ряду называет число ошибок точно по Canon: «Четыре следа узнают ошибочно; пятый скрыт от цифрового контроля». Она же передаёт эстафету: «чем является каждый режим, раскрывает досье AXIOM ∅ в разделе персонажей». Нумерация продолжает такты: 01 надежда, 02 разлом, 03 доктрина, 04 вопросы, **05 следы**. Рамки, глифы, hover и сетка из 5 колонок — исходные. BIO не раскрывает носителя: спойлер «вектор через VIKTOR» остаётся только в protected-блоках.

### P1 / AFTERMATH — порог вместо второго W04, человек вместо схемы

**AD-04. «Жизнь по допуску» = A08 `protocol_gate`.** Это вертикальный кадр 675×1200: длинный мост к монолитным вратам с красным «глазом». Не город, не локация, не персонаж. В кадр добавлены одна сканирующая линия через «глаз» врат, угловые скобки и подпись «ПОРОГ / ДОПУСК». Заголовок сцены — «Дальше — только по допуску.»: говорит сам порог. W04 остаётся только в WORLD GRID, проверка: 7 вхождений вместо 14.
> **Principal: YES, из качественного оригинала.** Источник — PNG 941×1672 из `AXIOM_SHOWCASE_VISUAL_LIBRARY_V1.zip`, SHA256 `736a2df3…` совпадает с `original_sha256` манифеста. Роль в манифесте — «вертикальный разделитель / карточка доступа», «декоративный образ контролируемого доступа». Производные — [`build_a08.py`](../../evidence/w4ad/preview/build_a08.py): AVIF 4:4:4 q80 / WebP q92, 480/720/941w, без апскейла, PSNR 41,7–43,2 дБ, сохранение резкости 0,95. Подключены через `srcset`. Мелкого текста в центре кадра нет: подпись снизу, через центр идёт только сканирующая линия.

**AD-05. «Помощь становится вопросом свободы» — новый объект.** Профиль человека с закрытыми глазами. От света в груди идёт живой пульс (ЭКГ), он проходит через кольцо системы и выходит квантованной ступенчатой волной к скобе «РАЗРЕШЕНИЕ». Над этим — «ЧЕЙ ЭТО СИГНАЛ?». Метафора: твоя собственная жизнь идёт через протокол, которым ты не владеешь. Без медицинских измерений, без устройства-персонажа. В обычном режиме по линии бежит одна световая точка, в RM её нет.

**AD-06. Ритм сцены.** Сначала ряд из двух колонок: порог и память, обе по 520 px, — мёртвая зона N3 исчезает. Затем зависимость — финальная сцена на всю ширину. Это даёт третьей теме собственный вес, которого просил Principal.

### P1 / MOBILE — мобильная режиссура, а не стопка колонок

**AD-07. Ленты с привязкой (scroll-snap) для повторяющихся полноценных объектов**, только ≤760 px:
- **Пять следов.** Горизонтальная лента, карточка 84 % ширины, видна кромка следующей. Под лентой `← 01 / 05 →`.
- **Четыре этюда.** Индекс 2×2 (`01 CHRONICLE … 04 WATCH_DOG`), затем лента полных модулей 90 % ширины одинаковой высоты, под ней `← 01 / 04 →`.
- Компоненты не урезаны, не свёрнуты и не грузятся по требованию: в DOM и на экране полный исходный модуль со всеми SVG.
- **Без JS:** нативная горизонтальная прокрутка, индекс — обычные якоря.
- **Клавиатура:** лента фокусируема (`tabindex=0`, `role=region`), стрелки прокручивают. Кнопки и пункты индекса ≥ 44 px.
- **Desktop не меняется:** 5 колонок следов, сетка 2×2 этюдов.

### P2 / WORLD GRID — заголовок, который есть только у AXIOM
