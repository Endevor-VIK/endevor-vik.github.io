## Риск

Лендинг публикуется через GitHub Pages из этого репозитория. После merge в `main` около 77 МиБ доказательств (`docs/showcase-v031/evidence/**`) станут частью публичного дерева сайта и истории `main`. Это не дефект дизайна, но:
- репозиторий и клоны вырастают в несколько раз;
- внутренние кадры, отчёты и инструменты QA становятся публично адресуемыми по URL сайта.

## Варианты на решение CREATOR перед Gate B / merge

1. **Рекомендую:** закрепить полный PR #12 неизменяемой ссылкой (tag `0524-w4r-evidence-<sha>` или архивная ветка) с манифестом SHA256. В `main` перенести только продукт, тесты, `waves/*` и сжатый индекс доказательств со ссылками на тег. Доказательства сохраняются целиком и проверяемо, но не публикуются сайтом.
2. Слить как есть (просто, но +77 МиБ в публичном дереве).
3. Вынести `evidence/**` в отдельный репозиторий или release-архив с хэшами.
