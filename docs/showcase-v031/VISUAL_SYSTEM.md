# AXIOM SHOWCASE V0.3.1 — VISUAL SYSTEM (черновик W0)

> Статус: **предложение для AXIOM Principal Review и CREATOR**. В W0.1 токены не внедрялись — исправлялись только технические дефекты. Внедрение — W1 (первый экран, ABOUT, WORK), затем остальные секции.

## 0. Что есть сейчас (замер)

- **Три параллельных набора токенов:** `--bg/--ink/--mute/--red…` (`index.css`), `--ax-*` (локальный для сущности AXIOM), `--ax23-*` (`showcase-v23.css`).
- **162 различных hex-литерала, 318 использований** в 4 CSS-файлах; бренд-красный `#ff2034` записан литералом 44 раза вместо токена, `#b4b8c3` — 34 раза; 56 разных оттенков красного семейства; 27 литералов в пурпурно-фиолетовом диапазоне оттенков 270–345° (часть — допустимые кримсон-винные рамки, часть — запрещённые сливовые фоны).
- **Шрифты:** 5 семейств, 16 начертаний (см. `AUDIT_REPORT.md` A-GLB-03).
- **Размеры текста:** 59 % текстовых элементов < 12 px.

**Запрещено (контракт для smoke-проверки в W1):** фоны и градиенты с оттенком 270–345° при насыщенности > 0,15 (сливовые, пурпурные, фиолетовые), светло-розовые и лососевые (`#ff8a92`, `#ff7d88`, `#f7cdd3`, `rgba(255,138,146,…)`, `rgba(255,80,100,…)`), мятно-зелёные акценты. Исключения из оригинальной графики (эмблема/радар HERO, глитч лоадера) — только решением CREATOR (`OPEN_ISSUES.md` Q-04).

**Метод контроля:** пиксельная выборка фона по каждой секции (`palette-background-sampling` в evidence) — цель < 5 % пурпурных тёмных пикселей на секцию.

## 2. Шрифты и роли (предложение)

### 2.1 Варианты набора семейств

| Вариант | Семейства | Начертания | Что меняется визуально | Рекомендация |
| --- | --- | --- | --- | --- |
| **A** | Oswald (дисплей) + JetBrains Mono (метки/данные/HUD) + Golos Text (проза) | ≈ 7 (Oswald 500/600, Mono 400/600/700, Golos 400/600) | Новые секции получают заголовки в языке HERO и лора (Oswald), уходят Unbounded и Tektur | **Рекомендовано**: идентичность RED PROTOCOL сохраняется, одна система заголовков, читаемая кириллица в прозе |
| B | Oswald + JetBrains Mono + Golos + Unbounded (только h2 новых секций) | ≈ 8 | Сохраняется «широкий» голос новых секций, Tektur уходит | Если CREATOR ценит Unbounded как голос «витрины» |
| C | Как сейчас (5 семейств) | 16 | — | Не рекомендовано: 2 конкурирующие системы заголовков, вес, CLS |

Лицензии: Oswald, JetBrains Mono, Golos Text, Unbounded, Tektur — SIL OFL 1.1 (Google Fonts) → самостоятельный хостинг разрешён; в W1 — подмножества `latin` + `cyrillic` (+ `cyrillic-ext` только при необходимости), `woff2`, `font-display: swap` + метрические фолбэки (`size-adjust`, `ascent-override`) для Oswald, чтобы убрать сдвиг 0,0699.

## 3. Пространство и сетка

- Шкала отступов: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128.
- Вертикальный ритм секций: 96–120 px (десктоп), 72 px (планшет), 56 px (телефон).
- Поля: 36 px (десктоп, как сейчас), 24 px (планшет), **16 px** (телефон; сейчас 14 px).
- Контейнер 1440 px (как сейчас); мера текста ≤ 70ch, лида ≤ 62ch.
- Сетка 12 колонок, межколонник 24 px (десктоп) / 16 px (телефон); композиции секций выражаются через неё, а не через свои `grid-template-columns` в каждом слое.
- Брейкпоинты (сводятся из 540/550/640/720/760/900/1080/1100/1160): **≤ 600** телефон · **601–900** планшет · **901–1200** ноутбук · **> 1200** десктоп; плюс `(max-height: 600px)` для низких окон и 200 % zoom.

## 4. Примитивы

| Примитив | Состав | Правило |
| --- | --- | --- |
| Frame | волосяная рамка + угловые засечки | Для «экранных» объектов (stage, карта, сущность AXIOM); не для каждой карточки |
| Panel | `--ax-surface` + `--ax-hairline` | Базовый контейнер |
| Card | Panel + заголовок роли Card title | Не более одного ряда одинаковых карточек подряд |
| Button / primary | `--ax-crimson` заливка, Label, ≥ 44 px; **текст `#0a0507` (5,31:1)** — белый на `#ff2034` даёт только 3,81:1 | Одна главная кнопка на экран; альтернатива — более глубокая заливка с белым текстом (решение CREATOR) |
| Button / ghost | рамка `--ax-crimson-deep`, Label | Вторичные действия |
| Chip / status | Label в рамке | Смысловой статус ≥ 11 px |
| HUD label | Micro-HUD | Только украшение |
| Bridge | полоса-переход между секциями | Один текст-вопрос, без трёх нумераций |
| Figure | изображение + Caption внизу | Без «служебных» подписей |

**Композиция по типу содержимого** (вместо «одна сетка 4 карточек везде»):

| Секция | Ведущий приём |
| --- | --- |
| HERO | Кинематографичный: заголовок + радар + один CTA + один вторичный ряд |
| WHAT IS AXIOM | Редакционный: лид + иллюстрация + 3–4 тезиса в строку текста, не карточками |
| WORK | Визуальный: один архив (stage + список + панель кейса) |
| SYSTEM | Диаграммный: поток CANON → GRAPH → WEB CORE → AXCHAT как схема |
| WORLD-гид / лор | Редакционный + оригинальная графика наследия без изменений |
| VISION | Временная шкала 4 этапов со статусами |
| CONTACT | Короткий список + один канал связи |

## 5. Движение

| Уровень | Длительность | Свойства | Правило |
| --- | --- | --- | --- |
| Микро (hover/press) | 120–200 мс | `transform`, `opacity`, цвет рамки | `translateY(-2…-3px)` |
| Фокус | мгновенно | `outline` токеном `--ax-focus` | всегда видим при клавиатуре |
| Выбор (stage, узлы, шаги) | 200 мс | цвет/фон/рамка | без смещения макета |
| Вход секций | 600–800 мс один раз | `opacity` + `translateY(16–24px)` | при переходе по якорю — без анимации (сделано в W0.1) |
| Фоновые петли (радар, сканлайны) | ≥ 4 с | **только `transform`/`opacity`** | пауза вне экрана (IntersectionObserver) |
| reduced-motion | — | — | без петель и входов; SMIL на паузе (W0.1); лоадер не показывается |

Запрещено по умолчанию: анимация `top/left/width/height` в петлях, `filter`-анимации на больших площадях, постоянные полноэкранные canvas/iframe.

## 6. Решения по экранам (кандидаты для W1, требуют подтверждения)

1. **HERO:** сохранить композицию KNOWLEDGE / CONTROL / ACCESS, радар, рамку, ENTER AXIOM. Под CTA — один ряд: «Что такое AXIOM · Работы · Будущее» (Label, ≥ 44 px). Строки-контекст и подпись — в ABOUT. Метки 01/02/03 — только ≥ 1536 px. Статус-карту и «00 / ENTRY» не показывать одновременно. На 1024 px — компактный радар рядом с заголовком.
2. **WHAT IS AXIOM:** h2 в роли Section display (Oswald); тезисы — без повторов SYSTEM.
3. **WORK:** два макета на выбор CREATOR — (а) «архив»: stage + вертикальный список + панель деталей; (б) «главный кейс + архив»: реальный публичный экран как герой, ниже архив. В обоих — один показ каждого скриншота, детали кейса без шаблонных строк.

## 7. Как проверяется

- Палитра: пиксельная выборка по секциям < 5 % пурпурных тёмных пикселей; smoke-список запрещённых литералов.
- Типографика: инвентарь размеров (`probe.cjs`) — смысловые подписи ≥ 11/12 px; запросов к `fonts.googleapis.com` нет; сдвиг «Web font loaded» < 0,01.
- Контраст: axe `color-contrast` = 0 в изменённых секциях.
- Регрессия: `tests/browser/showcase_regression.cjs` + полный набор снимков «до/после».
