# AXIOM SHOWCASE — WORLD LIBRARY (W3.C · 0524)

Источник — архив CREATOR `0524.zip` от 2026-10-19 (sha256 `5276d240…0a3454`). В архиве **9 файлов** PNG 1672 × 941 (16:9), RGB, без ICC-профиля. В директиве упомянуты десять изображений, но в архиве их девять; расхождение отправлено CREATOR.

Статус: **библиотека импортирована в ветку `w3/c-world-immersion`. На страницу ничего не подключено.** Места использования — предложения W3.C (`docs/showcase-v031/waves/W3C_WORLD_CONCEPTS.md`), их утверждает CREATOR.

## Структура

```
world-library/
  README.md        — этот файл: описание каждого изображения
  manifest.json    — машиночитаемый манифест: uuid, sha256, размеры, байты, проверки, роль, Canon, предложенное место
  originals/       — исходные PNG, байт-в-байт как в архиве, под исходными именами-UUID
  web/             — производные для сайта: Wnn_<slug>-<ширина>w.avif|webp
```

- **Оригиналы.** Не менялись: проверено `sha256sum -c` против распакованного архива. Страница их не загружает.
- **Производные.** Ширины 960 / 1280 / 1672 px. 1672 — родная ширина, увеличения нет.
  - **AVIF** 4:4:4, quality 80 — основной формат: PSNR 40,2–43,7 дБ, сохранение резкости контуров 0,94–0,97.
  - **WebP** q92 — запасной формат: PSNR 35,0–42,6 дБ (у WebP цвет всегда 4:2:0, поэтому мелкий насыщенный красный теряет точность), сохранение резкости 0,95–0,99.
  - Сохранение резкости считается так: дисперсия лапласиана кодированного кадра ÷ эталона LANCZOS; 1,00 — без смягчения.
- **Размеры.** Все производные — 9,5 МБ, оригиналы — 20,0 МБ. Страница грузит только 1–2 файла на изображение по `srcset`/`sizes`, и только лениво (`loading="lazy"`), потому что всё ниже первого экрана.
- **Предел резкости.** Родная ширина 1672 px. При `object-fit: cover` на экране @1 изображение остаётся резким до ~1672 css px нарисованной ширины. На retina (@2) резко до ~836 css px. Шире на retina будет мягче устройства — это предел исходника; лечится только более крупным мастером от CREATOR.

## Правила

- Это художественные материалы, **не** достоверные изображения мест, событий или персонажей Canon. Подписи и `alt` не привязывают их к Canon по сходству (как в `visual-library/README.md`).
- Карту V10 они не заменяют.
- Текст поверх изображений — только HTML на градиентной маске. Впечатанные в картинку надписи не используются как сюжетный текст.
- Палитра проверена: доля пурпурно-фиолетовых пикселей (тон 260–340°, насыщенность > 0,25) — 0,00–0,04 %. Розового и фиолетового нет.
